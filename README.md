# Plateforme de Gestion de Stages

Projet de fin de module UML.

Cette application permet de gérer le processus complet des stages :

- publication d'offres de stage
- consultation des offres
- candidature des étudiants
- validation des stages
- évaluation des stagiaires

## Technologies utilisées

Backend
- Node.js
- Express
- MongoDB
- Mongoose
- JWT Authentication

Infrastructure
- Docker
- VPS OVH

Frontend
- React (à venir)

## Architecture

Frontend → API Express → MongoDB

## Installation

Cloner le projet :

git clone https://github.com/USERNAME/stage-management-platform

Installer les dépendances :

npm install

Lancer le backend :

node src/server.js
